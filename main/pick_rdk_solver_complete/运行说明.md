# pick识别 + 压缩包原恢复算法

主程序：`pick_base_rdk_solver.py`

识别部分保留 `pick_base(9).py`：手动A4四角标定、840×1188透视校正、亮色碎片分割、3～5边多边形拟合、面积排序。

恢复部分直接调用原压缩包中的：

- `solve_fixed`：已知固定四片；
- `solve_taught` / `solve_unknown`：未知白色碎片；
- `solve_card`：扑克牌图案碎片。

没有重新写一套近似算法；`puzzle_vision` 目录来自压缩包。所有动作仅包含旋转和平移，不允许单块镜像和缩放。

## 运行

```bash
python3 -m pip install opencv-python numpy
python3 pick_base_rdk_solver.py
```

## 按键

- `P`：按当前模式恢复；默认是AUTO。
- `M`：循环 AUTO、已知、未知、扑克牌。
- `0/1/2/3`：直接选择 AUTO、已知、未知、扑克牌。
- `T`：显示或隐藏目标叠加。
- `D`：输出识别边长、吸取点、放置点、位移和旋转角。
- `C`：重新标定A4四角。
- `A`：面积参考框。
- `Q/ESC`：退出。

AUTO会依次结合碎片内部图案、固定模板误差、未知矩形填充验收选择三种原求解器之一。现场调试时可以使用`1/2/3`强制指定，避免自动分类受曝光影响。
